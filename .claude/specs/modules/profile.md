# Module: Public Profile

## URL
`planster.app/@[username]`

## Visible without authentication
Any visitor can see the profile.

## Profile content
- Profile picture (circular, 120px)
- Display name and @username
- Bio (max 300 chars)
- If the user is a writer: grid of cover images of their published books (click → book page)
- If the user has public shelves: shelf list with book count
- Number of books in library (if the user has made it public in settings)

## Profile settings (`/settings`)
- Edit: profile picture, display name, bio, username
- Toggle: show number of library books on public profile
- Toggle: show ratings and reviews left on public profile
- Change password (only if the user registered with email)
- Disconnect Google account (if they also have email+password)
